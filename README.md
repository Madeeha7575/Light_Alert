Light Alert Raspberry Pi💡
A simple light detection and alert system built using a Raspberry Pi, photosensor (LDR), LEDs, buzzer, and transistor.

📌 Project Overview
Detects ambient light using a photosensor (LDR).
Red LED + buzzer blink when it’s dark.
Green LED blinks when it’s bright.
A transistor is used to safely drive the buzzer without overloading GPIO pins.

⚙️ Components Used
Raspberry Pi 
LDR (Light Dependent Resistor)
Red LED
Green LED
Buzzer
Transistor 
Resistors & jumper wires
Breadboard

Logic:
Dark → Red LED blinks + buzzer beeps
Bright → Green LED blinks
